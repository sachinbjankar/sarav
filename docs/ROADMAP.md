### निकालापूर्वी निकाल — नवीन परीक्षा जोडण्याची पद्धत
1. परीक्षेच्या दिवशी प्रश्नपत्रिका PDF मिळवणे → प्रश्न `public/pyq/<id>.json` मध्ये (मागील प्रश्नपत्रिकांसारखे).
2. तात्पुरती उत्तरतालिका (आपली/तज्ञांची) प्रत्येक संचासाठी → `content/nikal_build.py` मध्ये नोंद, `status: 'provisional'`.
3. `python3 content/nikal_build.py` → app मध्ये लगेच दिसते (अ‍ॅप अपडेटशिवाय नंतर GitHub वरून आणणे — पुढील काम).
4. आयोगाची अंतिम उत्तरतालिका आल्यावर key बदलून `status: 'final'` → सर्वांचे गुण आपोआप बदलतात.
- पहिले लक्ष्य: **गट-क पूर्व परीक्षा, २४ जानेवारी २०२७** — परीक्षेनंतर २ दिवसांनी (२६ जाने.) उत्तरे भरणे सुरू.
- आगामी परीक्षांचे काउंटडाउन: `public/nikal/index.json` (परीक्षा ↔ notices.json मधील id). तारीख notices.json मधून येते; `file` भरल्यावर “LIVE”.
- २०२३ चा पेपर फक्त “नमुना पाहा” दुव्यासाठी ठेवला आहे (नको असल्यास index मधून काढा).
